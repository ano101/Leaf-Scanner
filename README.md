# Leaf — сканер документов для iOS

Бесплатное офлайн-приложение: сканирует бумаги, хранит их и отдаёт наружу
файлом нужного веса. Ни одного сетевого запроса, ни аккаунтов, ни сервера.

## Зачем

Разбор рынка показал устойчивую картину: Scanner Pro, SwiftScan и Adobe Scan
держат за подпиской операции, которые занимают две секунды, — слияние,
распознавание текста, сжатие. Самая частая жалоба: скан с iPhone весит
десятки мегабайт, а отправить нужно файл меньше мегабайта, и люди ставят
второе приложение только ради сжатия, где упираются во вторую подписку.

Здесь всё это бесплатно и работает на устройстве. У приложения нет расходов,
поэтому обещание не превратится в подписку через год.

## Что умеет

- Съёмка системным сканером и ввод готовых снимков из «Фото» и «Файлов».
- **Файл заданного веса**: пресеты требований учреждений или свой размер,
  с показом итогового веса и самой тяжёлой страницы до сохранения.
- **Безвозвратная замазка** личных данных: пиксели уничтожаются, текстовый
  слой вырезается. У большинства приложений это прямоугольник поверх,
  из-под которого текст копируется.
- Распознавание текста на устройстве и поиск по нему.
- Поворот, обрезка, цветовые режимы, слияние и разделение документов.
- Двусторонняя стопка: две пачки собираются в один документ.
- Обнаружение повторных сканов.
- Папки, пароль на PDF, замок на входе, печать и отправка.

## Как собрать

```bash
brew install xcodegen
make test    # прогон всех проверок
make build   # сборка под симулятор
```

Опоры: Swift 6.2, iOS 26, Xcode 26.3, GRDB 7.11.1 — единственная сторонняя
зависимость, взятая ради полнотекстового поиска.
